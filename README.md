# 🐛 Червячки — Worms Web

Браузерный клон Worms на чистом Canvas/JS: один `index.html`, без сборки и зависимостей.

**Играть:** https://pavel-ai-dev.github.io/worms-web/
**Все игры:** https://pavel-ai-dev.github.io/games/

## Режимы
- 🤖 Против компьютера
- 👥 Вдвоём за одним устройством (hot-seat: красные — синие по очереди)

## Что внутри
- Разрушаемая земля (пиксельная маска), ветер, вода поднимается с 5-го раунда, ящики с аптечками и патронами
- 29 видов оружия: базука, самонаводка, граната, кластерная, банановая, святая граната, дробовик, пистолет, узи, миниган,
  огненный кулак, бита, топор, тычок, драконий шар, камикадзе, динамит, мина, овца, авиаудар, напалм,
  паяльная лампа, отбойник, балка, верёвка, парашют, телепорт, пропуск хода, сдаться
- ИИ: перебор угла и силы с симуляцией траектории, дробовик и кулак вблизи, авиаудар
- Графика и звук — из [Hedgewars](https://hedgewars.org) (GPL-2.0), папка `assets/`

## Управление
| Действие | Клавиши |
|---|---|
| Ходить / прицел | ← → / ↑ ↓ (или WASD) |
| Прыжок | Enter |
| Выстрел | Пробел — удерживать и отпустить (сила) |
| Оружие | Tab, Q или правая кнопка мыши |
| Таймер гранаты | 1–5 |
| Цель (самонаводка, авиаудар, напалм, балка, телепорт) | тап/клик по карте |
| Камера | перетаскивание |
| Заново | R |

На телефоне — экранные кнопки.

## Локальный запуск
```
python -m http.server 8765
```
и открыть http://127.0.0.1:8765/ (через `file://` браузер не даст загрузить ассеты).
